## Sprint Expansion Note (2026-05-16)

Rationale: codex dev had reliability incidents on 3.2 (network failure → fallback to claude) and 3.5 (deferred to claude per Codex→Claude handoff rule). Pinning dev=claude removes the failure mode while still honoring the Cross-Model Review rule (review=codex on every story). If codex review is unavailable on a given story, fallback=claude — orchestrator must then flag the cross-model violation and require manual override before continuing.
